# 05 — User Flows

> Source section: 6 of the original AI-Mentor-HUB project overview.

---

## Newcomer Flow

```
Login → Dashboard → Choose Simulator Module
  → OpenAccountSim / DepositSim / TransferSim / KYCScenario
    → Complete Task with AI Guidance
      → Receive Feedback & Score → Progress Database
```

At any point: Ask AI Knowledge Base → Instant answer in Uzbek or Russian

## HR Flow

```
Login → View Employees & Newcomers → Check Free Mentors
  → Assign Mentor → Track Progress → Export to iSpring LMS
```

## Overall System Flow

```
Newcomer → Dashboard → Simulator + AI Assistant → ProgressDB
HR → HR_Dashboard → Assign_Mentor → Mentor → Newcomer
```
