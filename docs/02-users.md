# 02 — Users (Empathize Phase)

> Source section: 3 of the original AI-Mentor-HUB project overview.

---

## HR Specialist

- **Goal:** Quickly onboard newcomers without security risk
- **Needs:** Centralized system, mentor visibility, progress tracking, LMS export
- **Frustrations:** Manual work, no real-time data, no mentor availability view

## Existing Employee (Mentor)

- **Goal:** Mentor newcomers with minimal extra load
- **Needs:** Clear assignments, AI handling routine questions, minimal disruption
- **Frustrations:** Repetitive questions, unclear responsibilities

## Newcomer / Intern

- **Goal:** Learn bank operations safely before getting real access
- **Needs:** Safe simulator, AI guidance, structured learning path
- **Frustrations:** No training environment, information overload, no real system access
