# 07 — Non-Functional Requirements & MVP Acceptance

> Source sections: 8 and 10 of the original AI-Mentor-HUB project overview.

---

## 8. Non-Functional Requirements

| Requirement   | Specification                                        |
| ------------- | ---------------------------------------------------- |
| Response time | Chatbot answers in ≤ 2 seconds                       |
| Security      | No real client or bank commercial data used anywhere |
| Data safety   | 100% synthetic training data (Data Leak Prevention)  |
| Platform      | Web + mobile responsive;                             |
| Languages     | English, Uzbek and Russian                           |
| LMS           | iSpring integration for progress export              |

---

## 10. MVP Acceptance Criteria

- [ ] At least **1 bank system simulator** fully working with AI chatbot
- [ ] Onboarding time reduced by at least **30%** in intern test group
- [ ] **iSpring LMS** integration successfully transmitting results
- [ ] **Zero** real client or bank commercial data used
- [ ] Chatbot response time consistently **≤ 2 seconds**
- [ ] Platform accessible on both **web and mobile**
