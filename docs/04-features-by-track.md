## Track 1 — Knowledge Base for Bank Employees

| Feature               | Description                                                                                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI Q&A Chatbot        | Answers questions like "What documents are needed for a loan?", "How do I open a foreign currency account?", "What to do in case of a suspicious transaction?" |
| Document Search       | RAG-powered search across internal regulations, SOPs, and policy documents                                                                                     |
| Next Step Suggestions | AI suggests the employee's next action based on context                                                                                                        |
| Multilingual Support  | Full support for Uzbek and Russian                                                                                                                             |
| 24/7 Availability     | Always-on, no dependency on human staff                                                                                                                        |

**Bonus features covered:** AI assistant ✓ · Uzbek & Russian ✓ · User-friendly interface ✓ · Voice assistant (planned MVP+) ✓

## Track 3 — Employee Skills Analysis Platform

| Feature                  | Description                                                           |
| ------------------------ | --------------------------------------------------------------------- |
| Skills Map               | Visual map of every employee's current skill profile                  |
| Skill Gap Analytics      | Identifies what training is needed per person and per team            |
| Promotion Readiness      | Flags who is ready for the next role                                  |
| Training Recommendations | AI recommends next modules based on current gaps                      |
| Forecasting              | Predicts employee development trajectory over time                    |
| Analytics Dashboard      | Charts for team skill distribution, progress trends, completion rates |

**Bonus features covered:** Attractive dashboards ✓ · AI analytics ✓ · Forecasting ✓
